# Система управления рецептами и списком покупок (OOP & Testing)

## Краткое описание
Проект представляет собой систему управления рецептами и автоматического формирования списка покупок. В проекте реализованы базовые принципы ООП. Корректность работы логики проверена с помощью модульных тестов.

## Использование (как запускать код и тесты)
Для того чтобы развернуть проект на своем компьютере и запустить тесты, выполните следующие команды в терминале:

1. Склонируйте репозиторий:
   
   git clone https://github.com/nastuskabantik/tp-hw2.git
   cd tp-hw2

2. Установите необходимые зависимости (библиотеку pytest):
   pip install -r requirements.txt

3. Запустите автоматические тесты:
   pytest
